# 简体中文术语表（zh）

Machine-drafted glossary for reviewers. Change a term here and everywhere in this folder (`grep` the old form).

## Conventions

| Topic | Choice |
|-------|--------|
| Form of address | **你** throughout (never 您) |
| Quotation marks | Mainland curly quotes **“ ”** (single ‘ ’ only nested); never 「」 |
| Punctuation | Full-width in Chinese text: ，。：；？！（）…… Use ASCII inside placeholders, syntax, paths, keys (`codex: {id}`, `[TODO: …]`, `Ctrl/Cmd+Shift+C`) |
| Spacing | One space between Chinese and Latin words / digits / numeric placeholders (`{count} 个场景`, `Inkswell 项目`, `第 {line} 行`). **No** space around placeholders filled with names or translated labels (`打开{name}`, `向{series}添加一本书`), since they usually hold Chinese text. No spaces between Chinese characters |
| Ellipsis in menu items | Keep the single `…` of the English UI (`重命名…`) |
| Counting words | Always **字** (`{count} 字`, 字数, 字/分钟). The counter already counts CJK characters |
| Plurals | Chinese has only `.other`; `.one` holds the same text |
| Sentence style | Short labels without 。; full sentences end in 。 |
