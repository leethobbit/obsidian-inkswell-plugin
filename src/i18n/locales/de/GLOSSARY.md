# German (de) glossary

Machine-drafted catalog. Keep these terms consistent across all files in this folder; if you change one, search the folder and change it everywhere.

## Form of address and style

| Topic | Choice |
|-------|--------|
| Address | **du** (informal), throughout: imperatives use the du form ("Wähle", "Schreib", "Lege … an") |
| Quotation marks | German „…“; nested/literal UI names in „…“ too |
| Apostrophe | typographic ’ ("So funktioniert’s", "Los geht’s") |
| Dash | spaced en dash " – " (not the English em dash) |
| Ellipsis in menu items | space before: "Umbenennen …", "Neue Szene …" |
| Percent | space before %: "{percent} %" |
| Error notices | "X konnte nicht … werden." (passive, no "Inkswell couldn't") unless Inkswell is the subject in English |
| Toggle commands | "… ein/aus" (e.g. "Fokusmodus ein/aus (Schreiben)") |
