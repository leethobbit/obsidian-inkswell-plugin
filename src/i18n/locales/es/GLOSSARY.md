# Spanish (es) glossary

Neutral Spanish for Spain and Latin America. Machine-drafted; reviewers, keep these terms consistent across the folder (search before changing one).

## Conventions

| Topic | Choice |
|------|--------|
| Form of address | **tú**, everywhere (imperatives: *elige, abre, añade*). No *usted*, no voseo. |
| Quotation marks | **«…»** for every quoted UI name, title or placeholder value (`«{title}»`). Curly “ ” only where the string describes the smart-quotes feature's literal output. |
| Apostrophes | None needed in Spanish text; no straight `'` in any value. |
| Case | Sentence case for labels and headings (*Nueva escena*, *Registro de revisiones*). |
| Dashes in sentences | English em-dash asides became a colon, semicolon or comma, which reads more naturally in Spanish UI text. |
| Numbers | Percent with a space (`{percent} %`). Values the writer types (book number 0.5) and the gutter tags the code prints (1.5k) keep the dot, because that is what the app accepts and shows. |
| Notices | Failures use the impersonal *No se pudo …*; confirmations use *¿Eliminar …?* |
| Gendered placeholders | Strings where `{type}`, `{label}` or `{plural}` could be masculine or feminine are rephrased to avoid agreement (*Nueva entrada ({type})*, *Se ocultó {label}.*). |
