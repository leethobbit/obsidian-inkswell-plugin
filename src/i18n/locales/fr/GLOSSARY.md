# Glossaire français (fr)

Brouillon traduit par machine, à relire. Les termes ci-dessous sont utilisés partout dans `locales/fr/` ; si vous en changez un, changez-le dans tout le dossier.

## Conventions

| Sujet | Choix |
|-------|-------|
| Forme d'adresse | **vous**, partout (« Choisissez… », « votre manuscrit ») |
| Typographie | espace fine insécable (U+202F) avant `: ; ! ? %` et à l'intérieur de « … » ; apostrophe typographique ’ |
| Casse | casse de phrase pour les libellés (« Grille d'intrigue », pas « Grille D'Intrigue ») |
| Boutons de commande | « Activer/désactiver … » pour les commandes « Toggle … » |
| Échecs | « Impossible de … » pour « Couldn't … » |
| Laissés en anglais | noms de produits, `[TODO: …]` et autres mots-clés de marqueurs, clés de frontmatter (`codex:`, `status:`, `codex-project`…), noms de dossiers créés dans le coffre (« Writing log », « Inkswell conflicts », Templates, Ideas), Save the Cat, Story Circle, Romancing the Beat, Story Grid, BISAC |

## Points à vérifier en contexte

- Les libellés traduits par « Fiche » supposent que `{type}`/`{types}` reçoivent un nom de type (Personnage, Lieux…) ; plusieurs phrases sont tournées en « {types} : aucune fiche… » pour éviter les accords de genre.
- `analysis` (lisibilité, mots fréquents) repose sur des formules anglaises ; « Niveau scolaire » / « Facilité de lecture » ne sont que des libellés.
- « 1k, 1.5k » dans la description des repères reste au format que l'éditeur affiche.
